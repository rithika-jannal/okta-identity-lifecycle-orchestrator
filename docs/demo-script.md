# Demo

1. Joiner: create and activate an employee.
2. Mover: change department/role and show access difference.
3. What-if: preview a high-impact deactivation.
4. Approval: approve and execute.
5. Drift: change expected/actual access and detect mismatch.
6. Leaver: deactivate and clean access.
7. Export: export users to CSV.
